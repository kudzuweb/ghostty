Nu Disco: current vs warm purple

The proposed palette is sampled from the reference image: plum walls for the background, the neon window for magenta and the cursor, the monitors for cyan, the lamp and cat for amber, and coral for red. The image has no true green, so green is a mint that stays distinct from cyan. Each mock shows the sidebar with three tab groups and some typical terminal output.
